# M5 — compiler UI and meta

Scope: build screen with slot constraints and live projected stats, draft
flow, route selection, run report screen, unlock tree, run history, daily
seed, share codes.

## Exit criterion

- A full run is playable end to end on device with no debug affordances.
- Share code round-trip: encode a build, decode it on a second device,
  produce an identical hash.
- Save migration test passes: a v1 save loads into the current schema.
