# M4 — schematic shell

Scope: top-down renderer driven purely by the event log. Playback: pause,
step, scrub, jump-to-failure. Design token set locked — palette, line
weights, icon grammar, minimum 44pt touch target. Both orientations
supported, with rotation permitted mid-run: anchors and containers only, no
absolute positioning, no assumption about which dimension is longer. Can
begin against M1's sim while M3 tuning continues, provided the renderer is
written against the event-log contract rather than current balance numbers.

## Exit criterion

- Forward-vs-jump equality test passes: rendering tick N by playing the log
  forward from zero, and by jumping directly to N, produce identical view
  state.
- 60fps sustained on a Pixel 6a during the heaviest committed golden run.
- Layout tests pass at both reference viewports — 1080×2400 portrait and
  2400×1080 landscape.
- A rotate-mid-run case leaves the run's event-log hash unchanged (rotation
  is shell-only; if it changes an outcome or a log hash, that's a boundary
  violation and a release blocker).
- No numeric game constant appears anywhere under `shell/` outside layout
  and styling.
