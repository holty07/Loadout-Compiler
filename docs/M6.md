# M6 — onboarding and feel

Scope: first-run tutorial, sound, haptics, readability pass, accessibility
(colour-blind safe palette, text scaling, reduced motion, no information
conveyed by colour alone). Feel, readability and pacing are judgement calls
with no test to hang them on — build the mechanism, then hand it over for
human review. Do not claim this milestone done on agent verification alone.

## Exit criterion

**Human gate, not agent-verifiable.** Five people who have never seen the
game complete a run and can explain what killed them. That last clause is
the actual test.
