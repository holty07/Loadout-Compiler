# M0 — bootstrap

Scope: directory skeleton, `sim/fx.gd`, `sim/rng.gd`, `sim/log.gd`, the three data
schemas, `tools/lint.gd`, `tools/validate_data.gd`, `tools/run_tests.gd`,
`harness/sim_cli.gd`, and CI with the two-architecture hash comparison. No pipeline
logic, no encounter resolution, no facility generation, no module/enemy data beyond
minimal test fixtures, no rendering.

## Exit criterion

All of the following exit 0, from a clean checkout, on both `ubuntu-latest` and
`ubuntu-24.04-arm`:

```bash
godot --headless --script tools/lint.gd
godot --headless --script tools/validate_data.gd
godot --headless --script tools/run_tests.gd
```

```bash
A=$(godot --headless --script harness/sim_cli.gd -- run --seed 1234 --loadout fixtures/basic.json | grep log_hash)
B=$(godot --headless --script harness/sim_cli.gd -- run --seed 1234 --loadout fixtures/basic.json | grep log_hash)
[ "$A" = "$B" ]
```

and the `A` produced on `ubuntu-latest` is byte-identical to the `A` produced on
`ubuntu-24.04-arm` (`.github/workflows/ci.yml`'s `cross-platform-hash` job).

`tools/run_tests.gd` passing must include `tests/test_lint.gd` passing *because* it
planted a `randf()` under the lint's scan root and asserted `tools/lint.gd` rejected
it, not because the check was skipped. A lint that can't fail on a real violation
doesn't count as passing.
