# M3 — balance to targets

Scope: data-only iteration against the targets table in `docs/plan.md`.
Expand content to roughly eight modules per slot and eight enemy archetypes
as the space is validated. No sim code changes — a tuning pass that needs one
is a finding about the model and goes back through the `RULES:` process with
a golden-file update, not a `BALANCE:` commit.

## Exit criterion

Every row of the targets table is met, with the sweep report committed as
evidence in the same commit:

| Metric | Target |
| --- | --- |
| Median loadout win rate | 35–45% |
| Best discoverable build win rate | below 75% |
| Distinct builds clearing the game | 8 or more |
| Any single module's share of winning builds | below 60% |
| Trap builds (plausible, loses) | 3 or more |
| First-choke spread across 4 subsystems | none above 50% |
| Median run length | 6–9 minutes |

**Human review gate** — @Matt reads the report and plays ten runs. The
harness measures whether the numbers work; it cannot measure whether the
game is interesting, and this milestone is not done on agent say-so alone.
